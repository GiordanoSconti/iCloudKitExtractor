A reader’s index into iCloudKit Extractor: the symbols that carry identity, CloudKit restore, MMCS download, and Octagon/PCS unlock. Each row names the type or method, where it lives, and what it is for. For the narrative spine of MMCS / authorizeGet, see the code map; this page is the directory of symbols behind that story.

Paths are relative to src/iCloudKitExtractor/. GitHub deep links point at main.

7. Call-flow sketch

ICloudBackupOrchestrator.CompleteSignInAsync
  └─ GsaGrandSlamAuthService + Anisette provider + HSA2/SMS as needed
       └─ ICloudSession

Escrow / Octagon (when ADP needs KeySet)
  ├─ EscrowRecoveryService / OctagonBottleRecoveryService  (PIN + HSM)
  └─ OctagonRecoveryKeyUnlockService                       (RK, no RECOVER)
       └─ OctagonCuttlefishService.fetchViableBottles / fetchRecoverableTLKShares
            └─ CkksVaultService.OpenViewsAsync → session PCS / TLKs

ICloudBackupOrchestrator.DownloadSnapshotAsync
  └─ BackupDownloadService
       ├─ CloudKit Lock (CloudKitLockRequestBuilder) + EN/flist parsers
       ├─ CloudKitAssetService (PrivilegedBatch) → MmcsAuthBuilder
       ├─ UbChunkBuilder.BuildAuthorizeGetRequest / BuildDecryptPlan
       ├─ MmcsContentEndpoints + MmcsChunkAssemblySession (ranged GET)
       ├─ FileGroupFillDecrypt ← LiveFillPipeline ← FordMmcsDecryptor
       └─ BackupFilesystemWriter / Manifest builders
