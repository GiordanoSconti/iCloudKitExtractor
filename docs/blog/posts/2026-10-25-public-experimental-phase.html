Opening the public experimental phase

After months of private research, iCloudKit Extractor is available as a public repository. The goal is not a polished product release: it is to let other forensic practitioners inspect the approach, try Windows builds, and help pressure-test flows that commercial tools often leave incomplete.

The software targets difficult CloudKit/MMCS recoveries—including ADP-protected material when you already hold an Octagon PIN or Recovery Key. Private Apple surfaces move quickly; expect breakage and treat every build as research-grade.

Licensing is MIT, with ownership and attribution remaining with Forensis-Lab. Signed Windows packages are published on GitHub Releases when we cut a tag. Prefer recognition for the lab over tips.

If you want to contribute: open issues carefully, prefer well-reviewed patches, and never drop unlicensed third-party code. Preview access to the maintainer Anisette path stays invite-only—ask by email.
